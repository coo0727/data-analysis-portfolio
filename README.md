# data-analysis-portfolio
# 数据分析作品集

地理信息科学专业本科生，专注数据分析方向。8 个完整项目覆盖 SQL、Python（pandas）、数据可视化（matplotlib/folium）与空间分析（geopandas）。

## 项目索引

| # | 项目 | 方法与工具 | 关键发现 |
|---|------|-----------|---------|
| 1 | [电商用户行为分析](./project8-ecommerce-behavior/README.md) | pandas、漏斗分析、RFM 分层 | 广告投放贡献 58.3% 注册，但 7 日留存仅 53.0%；自然流量人均产出为其 1.42 倍 |
| 2 | [门店选址覆盖分析](./project6-site-selection/README.md) | geopandas、缓冲区覆盖、盈亏平衡 | P1 以全场最低临界毛利率 7.54% 胜出；盲区潜在日需求 22313 单 |
| 3 | [区域品类利润分析](./project4-retail-profit/README.md) | pandas、分组聚合、Excel 透视表复算 | 规模第一≠效率第一：华东销售额第一（783.9 万），华中利润率第一（23.0%），三品类贡献 71.5% 利润 |
| 4 | [低空轨迹时空分析](./project7-low-altitude-trajectory/README.md) | geopandas、轨迹时空分析、folium | 航班违规率 6.40%（禁飞区 14 架次）；第 38 周航班量环比 +28.9% |
| 5 | [城市销售空间分析](./project5-spatial-sales-analysis/README.md) | geopandas、sjoin、choropleth | 区域销售额差距达 8.7 倍；华南数码利润率 23.8% 全面领先全国均值 16.0% |
| 6 | [门店销售分析](./project3-store-sales-analysis/README.md) | pandas、分组分析、数据可视化 | 电子类单品类贡献 43.51% 销售额；最高门店销售额达最低门店的 1.38 倍 |
| 7 | [数据岗位薪资分析](./project2-salary-analysis/README.md) | pandas、分组对比 | 3-5 年经验岗位薪资较 1-3 年溢价 50% 以上；一线城市岗位密度与薪资双高 |
| 8 | [城市经济统计分析](./project1-city-economy/README.md) | pandas、分组对比、相关性分析 | 薪资水平与 GDP 规模高度相关（r=0.94）；一线城市薪资较二线高 37% |

> 数据说明：项目数据为模拟/脱敏数据，分析流程与结论为完整实战产出。
