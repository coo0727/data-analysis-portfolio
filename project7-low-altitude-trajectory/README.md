# 低空轨迹时空分析
## 业务问题
试运营合规性如何？航班增长趋势怎样？风险整改从哪切入？
## 数据概况
本次分析使用 344 架次飞行轨迹、4 周低空试运营周期数据；违规判定基准：官方公布禁飞区范围
## 分析方法
轨迹时空对齐 + 禁飞区空间叠加校验；周度时序环比趋势分析；违规路径可视化复盘
## 关键发现
- **禁飞越界为首要风险**：违规率 6.40%，其中禁飞区违规 14 架次占 63.6%
- **第 38 周放量**：航班量环比 +28.9%，需提前报备扩容空域
