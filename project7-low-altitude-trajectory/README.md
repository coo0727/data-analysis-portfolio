# 低空轨迹时空分析
## 业务问题
试运营合规性如何？航班增长趋势怎样？风险整改从哪切入？
## 数据概况
本次分析使用 344 架次飞行轨迹、4 周低空试运营周期数据；违规判定基准：官方公布禁飞区范围
## 分析方法
轨迹时空对齐 + 禁飞区空间叠加校验；周度时序环比趋势分析；违规路径可视化复盘
## 关键发现
- 试运营整体航班违规率 6.40%，其中闯入禁飞区违规共 14 架次，为首要合规风险来源
- 第 38 周航班量环比增长 28.9% 呈放量趋势，输出禁飞架次逐一路径复盘、优化航线边界避让余量两项整改方向
