# 城市经济统计分析报告
## 业务问题
GDP规模与居民收入水平完全同步吗？区域经济差距的核心体现在哪些维度？省份与城市层级的发展该如何协调平衡？
## 数据概况
本次分析使用国内多省份城市月度经济统计明细数据，覆盖多省份层级、不同能级城市的月度经济运行样本
## 分析方法
按省份与城市类型双维度分组聚合计算；GDP均值、薪资差异率、人均产出指标拆解；省份-城市梯队交叉对比分析；多维度可视化图表呈现
## 关键发现
**经济总量与收入水平高度相关但人均产出存在错位**：城市GDP与薪资水平相关系数达0.94，经济越发达的城市薪资普遍越高，但人口规模与人均GDP呈负相关（r=-0.77），经济体量领先不代表人均产出效率最优
**区域发展差距沿省份与城市层级双重分化**：省份间GDP均值差距近2倍（浙江2525亿 vs 湖南1395亿），一线城市薪资较二线城市高出37%（17062元 vs 12500元），统计检验证实同省内不同能级城市薪资差异显著
