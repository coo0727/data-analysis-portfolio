# 电商用户行为分析

## 业务问题
拉新渠道效果如何？高价值用户是谁、怎么维护？

## 数据概况
模拟电商用户行为数据：1200 名注册用户（广告投放 700 人占 58.3%、自然流量 300 人占 25.0%、社交裂变 200 人占 16.7%），
含三张表：用户表、行为事件表（浏览/加购/下单/支付，共 6061 条事件）、订单表（615 笔订单，含已支付/已取消/已退货三种状态）。

## 分析方法
漏斗分析（浏览→加购→下单→支付）、分渠道留存、RFM 用户分层

## 关键发现
1. 【广告投放 vs 自然流量的留存对比】
广告投放贡献 58.3% 注册，但 7 日留存仅 53.0%、人均 GMV 仅 63.08 元；自然流量人均 GMV 89.80 元、为其 1.42 倍
2. 【最重流失环节及其流失率】
  最重流失在浏览→加购：流失 457 人、流失率 38.1%，核心流失点集中在流量承接最前端
3. 【RFM 高价值用户数量和支付金额占比】
RFM 分层（395 付费用户）：明星用户 101 人占 25.6%；高价值用户中 49.0% 处于流失状态
