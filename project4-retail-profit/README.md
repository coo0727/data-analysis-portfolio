# 区域品类利润分析
## 业务问题
销售规模等同于盈利能力吗？核心利润来源于哪些品类？区域与品类资源该如何优化分配？
## 数据概况
本次分析使用 1.5 万条零售订单明细数据，覆盖多销售区域、全品类商品交易
## 分析方法
按区域与品类双维度分组聚合计算；销售额、利润率、利润贡献率拆解；规模-效率交叉矩阵分析；可视化看板呈现
## 关键发现
- 区域规模与盈利效率存在错位：华东以 783.9 万销售额居全场第一，华中以 23.0% 的利润率位列盈利效率首位，规模第一不等于效率第一
- 利润向核心品类高度集中：电脑、手机、平板三大品类合计贡献 71.5% 的总利润，输出区域投入向华中倾斜、核心三品类加大资源投入的调整建议
