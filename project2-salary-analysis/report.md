# 数据分析岗位招聘数据分析

## 分析目的
分析数据分析师岗位的薪资分布、城市分布、学历经验要求

## 数据来源
模拟招聘数据，覆盖4个城市30条岗位记录

## 探索性分析
本次通过多组可视化图表对招聘数据集开展探索性分析，从岗位城市分布、薪资整体分布、不同城市薪资差异、经验与薪资关系四个角度挖掘数据特征。

- **岗位城市分布**：从各城市岗位数量分布柱状图可以看出，岗位在城市间分布并不均衡，部分城市岗位供给数量明显高于其他城市，是招聘岗位的集中地；其余城市岗位数量偏少，反映出招聘岗位资源存在地域集中现象。
- **薪资整体分布**：观察正式岗位薪资分布直方图（附带密度曲线），正式岗位平均薪资整体呈现右偏分布，大部分岗位薪资集中在中低区间，高薪岗位占比较少，少数高薪岗位拉高整体的薪资上限，符合招聘市场的普遍薪资特征。
- **不同城市薪资差异**：各城市薪资箱线图展示了不同城市正式岗位的薪资水平离散情况。不同城市的薪资中位数存在明显差距，部分城市整体薪资水平更高，同时箱线图可观察到部分城市存在薪资异常高点；同一城市内部岗位薪资也存在一定波动，说明同一城市内部岗位薪资层级分化。
- **经验与薪资关系**：不同经验要求的平均薪资分组柱状图体现出经验对薪资的影响：随着经验要求提升，岗位平均薪资整体呈上升趋势。高经验门槛的岗位可以获得更高平均薪资，说明工作经验是影响岗位薪资的重要因素。

整合四张子图综合来看：岗位资源集中在少数城市，同时城市之间薪资水平拉开差距；薪资整体以中低端为主，高薪岗位稀缺；经验要求与薪资存在正向关联。后续可以进一步统计不同城市、不同经验档位下的薪资占比，开展显著性检验，量化各组之间薪资差异是否具有统计意义。

## 结论
1. **岗位资源高度集中在一线互联网城市，北京岗位供给最多**。样本中岗位主要分布在北京、上海、深圳、杭州四座城市，北京岗位数量领先；但薪资水平上深圳、杭州正式岗位平均薪资相对更高，上海整体平均薪资略低，说明岗位数量多并不等同于平均薪资最高，城市间岗位供给规模与薪资水平不完全匹配。
2. **工作经验是薪资的关键影响因素，3‑5 年经验岗位薪资显著高于 1‑3 年**。从透视表结果可以看出，同一城市内部，3‑5 年的高级数据分析师平均薪资远高于 1‑3 年岗位；1‑3 年经验岗位薪资集中在 17000‑22000 区间，3‑5 年岗位薪资可达到 30000 以上，经验提升能够带来明显的薪资涨幅。
3. **正式岗位薪资整体呈右偏分布，高薪岗位占比少**。大部分正式岗位薪资集中在 15000‑25000 元，少数高级分析师岗位拉高薪资上限；岗位的薪资下限与上限高度相关，相关系数接近 1，岗位的最低薪资越高，对应的最高薪资也越高。
4. **应届生实习与正式岗位薪资差距巨大**。应届生仅存在实习岗位，以日薪结算，整体薪资水平远低于正式岗位，实习岗位更多偏向实践积累，薪资回报较低。
