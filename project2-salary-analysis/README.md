# 数据分析岗位招聘数据分析
## 业务问题
薪资水平差距等同于城市能级差距吗？薪资增长的核心驱动来源于哪些维度？求职城市与经验定位该如何优化分配？
## 数据概况
本次分析使用四座城市数据分析岗位招聘明细数据，覆盖多能级城市、全经验档位岗位招聘样本
## 分析方法
按城市与工作经验双维度分组聚合计算；薪资均值、薪资溢价率、岗位密度占比拆解；城市-经验梯队交叉矩阵分析；可视化看板呈现
## 关键发现
**薪资驱动与城市层级存在错位**：3-5年经验岗位较1-3年（17000-22000元区间）薪资溢价达50%以上，经验梯队薪资差异显著，城市能级第一不等于薪资增长结构最优
**优质岗位向一线城市高度集中**：一线城市同时具备岗位密度与薪资水平双重优势，输出求职资源向一线城市倾斜、不同经验档位差异化定位的求职建议
