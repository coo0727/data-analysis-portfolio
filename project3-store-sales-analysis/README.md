# 门店销售分析
## 业务问题
销售规模差距等同于运营能力差距吗？核心销售额来源于哪些品类？门店与品类资源该如何优化分配？
## 数据概况
本次分析使用多家门店90天销售明细数据，覆盖多经营门店、全品类商品交易
## 分析方法
按门店与品类双维度分组聚合计算；销售额、品类贡献率、门店绩效差拆解；规模-梯队交叉矩阵分析；可视化看板呈现
## 关键发现
- 门店规模与运营质量存在错位：头部门店最高销售额达尾部门店的1.38倍，销售规模梯队差异显著，规模第一不等于运营结构最优
- 销售额向核心品类高度集中：电子类单品类贡献 43.51% 的总销售额，输出品类资源向电子类倾斜、尾部门店差异化运营的调整建议
