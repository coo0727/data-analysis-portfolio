# 门店选址覆盖分析

## 业务问题

现网覆盖够不够？盲区需求多大？新店开在哪？

## 数据概况

本次分析使用 42 个现有门店、360 个需求点位、8 个候选点位；覆盖判定半径：2000 米

## 分析方法

投影后 buffer 缓冲区覆盖计算 + 空间连接；候选点盈亏平衡分析；folium 可视化

## 关键发现

- 现网需求覆盖率 73.3%，盲区潜在日需求 22313 单（住宅小区占 70%）
- P1 以全场最低临界毛利率 7.54% 胜出（现实毛利率区间内优势稳定），输出首选 P1、次选 P5
