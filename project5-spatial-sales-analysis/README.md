# 城市销售空间分析

## 业务问题

销售表现与地理空间分布正相关吗？各区域的品类盈利机会有何差异？如何基于空间特征优化品类经营策略？

## 数据概况

本次分析整合门店销售交易数据与城市地理空间数据，覆盖多城市区域、全品类商品的销售与盈利指标

## 分析方法

门店点位与行政区划空间连接（sjoin）；分级统计地图（choropleth）可视化呈现；区域 - 品类盈利指标对标拆解；品类分层经营策略推导

## 关键发现

- 区域销售空间分化差距显著：头部与尾部区域销售额差距达 8.7 倍（1067.1 万 vs 9261.2 万），销售规模与地理分布并非线性对应，空间不均衡性突出
- 华南盈利效率领跑且品类需分层施策：华南全品类利润率全面领先全国，其中数码品类达 23.8%，高出全国均值 16.0%；据此输出品类分层经营策略：数码居首层核心经营、家居服饰居中均衡布局、食品按引流角色管理，不单一以利润率为标准一刀切
